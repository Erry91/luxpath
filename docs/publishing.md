## The owner's switches, in order

1. **Read the history once more yourself:** `git log -p` (eight commits). Commit authorship shows
   `enrico.sita@gmail.com`; it is already public on your other open-source contributions. To use GitHub's
   no-reply address for future commits instead, set it in the repository's git config before the next commit
   (history keeps the old address unless rewritten, which is not worth it).
2. **Make the repository public:** Settings → General → Danger Zone → Change visibility.
3. **Turn on private vulnerability reporting:** Settings → Code security → Private vulnerability reporting
   (`SECURITY.md` points to it).
4. **Protect `main`:** Settings → Branches → require a pull request and the CI checks (`gates (ubuntu-latest)`,
   `gates (macos-latest)`, `gates (windows-latest)`, `licences and advisories`). Public repositories get Actions
   minutes free, so hosted CI resumes; the first run tells us whether Windows needs fixes.
5. **Description and topics:** "Open, scriptable emergency-lighting calculations (EN 1838) in Rust"; topics such
   as `lighting`, `emergency-lighting`, `en1838`, `photometry`, `ies`, `eulumdat`, `rust`, `bim`.
6. **Code of conduct (optional):** Insights → Community → Code of conduct → Contributor Covenant, generated by
   GitHub in one click.
7. **Discussions (optional):** useful for practitioners who want to ask rather than file issues.

## Decisions for later

- **crates.io:** the `luxpath` name was free on 2026-10-16. Reserving it means publishing a version (a placeholder
  or the current pre-alpha library); then `publish = false` comes off the crates to publish. Publishing a
  life-safety library before M4 and M6 invites use before validation, so the suggestion is to wait for alpha and
  watch the name meanwhile.
- **Announcement:** wait for alpha (M4 checks and M6 validation). Before it, share the repository directly with
  people who can help: designers with DIALux or Relux licences for M6, people with real photometric files.
- **Ashlar's plugin (R2.9)** builds on the public library from then on.
